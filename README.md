# NFL Forecast Engine — LevLine

A free, automated NFL forecasting project inspired by Sujar Henry's public methodology and extended with leakage-safe feature engineering, walk-forward ensembles, score forecasts, uncertainty, market information, and immutable pregame accountability.

**Deployment status:** live on GitHub; automated forecasts publish from GitHub Actions into `outputs/`.

## Official winner-probability model

Beginning with production version `0.9.0-fst`, the official winner probability is the frozen `F-ST-01-FROZEN-2026` model. For a game with a usable current vig-free moneyline probability, F-ST combines exactly two logit inputs:

1. current vig-free `market_home_prob`; and
2. `fst_pure_home_prob`, the leakage-safe fully nested football-only PURE probability produced by the validated season-forward base-model/meta-model stack.

The frozen scoring equation is:

```text
logit(final_home_prob) =
    -0.06954359363166639
    + 1.1939087340527093 * logit(market_home_prob)
    - 0.19342747983803402 * logit(fst_pure_home_prob)
```

The coefficients are loaded from the pinned production artifact `src/nfl_forecast/artifacts/F-ST-01-FROZEN-2026.json`; production does not refit them on each run. The artifact was fit on 1,615 leakage-safe OOF games from 2020–2025, uses training-data SHA-256 `6a26713b636a98298bb619982bb38b2e5dbb78816e093e6f910c1cee32ab5aa0`, and used zero 2026 outcomes for coefficient fitting or architecture selection.

The pre-F-ST LevLine model remains a prospective counterfactual. `pure_home_prob` keeps its legacy production meaning, and `legacy_final_home_prob` is computed exactly as the prior official rule:

```text
legacy_final_home_prob = pure_home_prob                    # market unavailable
legacy_final_home_prob = 0.75 * pure_home_prob
                       + 0.25 * market_home_prob           # market available
```

When a current market probability is missing or non-finite, F-ST is ineligible for that game and the official probability falls back to that exact legacy rule with an explicit `fst_fallback` flag and reason. The deployment does not synthesize a market probability and does not substitute a point spread for a moneyline probability.

Official locked rows additionally preserve the F-ST nested PURE, exact market snapshot used, legacy PURE, legacy 75/25 counterfactual, strategy identifier, model version, and frozen artifact identity. Historical locked predictions are not backfilled or rewritten.

### Rollback

The production scorer has a one-line regime switch in `src/nfl_forecast/fst_production.py`: change `ACTIVE_PRODUCTION_STRATEGY` from `F-ST-01-FROZEN-2026` to `current_production_75_25`. This restores the exact previous winner-probability behavior for future runs while retaining the expanded accountability schema and preserving every prediction already locked under F-ST.

## Design constraints

- **$0 data/API spend**
- **No manual weekly inputs**
- nflverse / `nflreadpy` is the primary data backbone
- 2026 remains a forward-test season for F-ST coefficient/architecture selection
- Every rolling football feature is shifted before the game it predicts
- Legacy production PURE and F-ST nested PURE remain distinguishable
- Historical predictions are appended, never overwritten
- Upcoming games receive team state from the latest completed game via a schedule-first scaffold
- Each run publishes only the next unresolved NFL week/slate
- Margin and total models remain separate from the official winner-probability promotion

## Model components

### Sujar baseline
- Elo
- recent win percentage via leakage-safe EWMA/rolling windows
- rest differential
- offensive EPA
- defensive EPA
- four-model ensemble: logistic, Extra Trees, XGBoost, CatBoost
- season-level expanding-window stacking

### Core Sujar+ / legacy PURE
- pass/rush EPA splits
- success rate
- neutral-game-state EPA
- rolling 3/5/8 form
- EWMA form
- offensive/defensive matchup differentials
- Elo with margin-of-victory update
- margin regression ensemble
- total regression ensemble
- projected scores
- model-disagreement metric
- vig-free market probability when moneylines exist

### F-ST nested PURE
F-ST's football-only input is not the live legacy `pure_home_prob`. It is generated by a separate production-safe reproduction of the validated research architecture: season-forward OOF predictions from the same four base-model templates feed a deterministic logistic meta-model, and future/live inference uses those nested semantics. Production does not import challenger/research modules.

### Advanced data adapters
The engine loads these on a best-effort basis without allowing a failure to block Core:
- Next Gen Stats
- FTN charting
- PFR advanced passing
- snap counts
- depth charts

Their feature integration remains separately validated research; player-availability or player-impact research is not silently inserted into F-ST.

## Run

```bash
python -m venv .venv
source .venv/bin/activate
pip install .
python scripts/run_week.py --season 2026 --snapshot EARLY
```

The primary dashboard feed is `outputs/this_week.csv`.

## Free Google Sheets connection

The simplest zero-credential deployment is a **public GitHub repository**. GitHub Actions updates `outputs/this_week.csv`; Google Sheets can read that file with `IMPORTDATA` from the repository's raw URL. This requires no Google API key, no service account, and no paid data provider.

Example raw base:

```text
https://raw.githubusercontent.com/YOUR_USERNAME/YOUR_REPO/main/outputs
```

Then the Sheet can use:

```text
=IMPORTDATA("https://raw.githubusercontent.com/YOUR_USERNAME/YOUR_REPO/main/outputs/this_week.csv")
```

## Market and historical-data note

Historical nflverse schedule lines are generally closing-market information. Live 2026 predictions use the current vig-free moneyline probability available to the production run. If the underlying source does not expose an independent quote timestamp, LevLine records the forecast/lock snapshot time rather than inventing bookmaker freshness metadata.

Completed 2026 games may update ordinary rolling football state/features where the existing pregame pipeline already supports that behavior. They do not refit, select, or mutate `F-ST-01-FROZEN-2026` coefficients or architecture.

## Accuracy-first research after F-ST deployment

Separate research tracks may evaluate sharper multi-book/timing market inputs, timestamped player availability, a separately registered forward-only 2026-updated candidate, and systematic F-ST-versus-legacy-versus-market disagreements. None of those tracks may mutate F-ST-01 in place or use early 2026 results retroactively while continuing to call the model `F-ST-01-FROZEN-2026`.
