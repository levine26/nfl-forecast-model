## Paid-source conclusion

The one paid data category that could materially change the scientific program is **timestamped historical multi-book odds/price movement**. It directly determines whether M1 can exist. The Odds API has the clearest self-service snapshot semantics; SportsDataIO documents the richest line-change history. Phase 2 should inspect sample data and pricing before any purchase decision. Do not spend money merely for more football statistics unless M2/M3 expose a specific PIT gap.

## Hard requirement

A provider is unusable for historical event-time features if it stores only the final corrected record without a reconstructable as-of history. SportsDataIO explicitly warns that its general historical archive does not preserve revision trails; betting line movement is an exception. The same distinction must be verified for every source.
