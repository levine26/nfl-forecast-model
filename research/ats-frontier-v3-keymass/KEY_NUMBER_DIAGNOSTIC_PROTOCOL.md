# Key-Number Diagnostic Protocol

Prospective diagnostics are fixed to exact margins `0`, `±3`, `±7`. Report predicted probability versus empirical frequency for each signed cell and aggregated absolute 3/7 where useful, with counts and uncertainty. Report push calibration separately for integer sportsbook lines.

These diagnostics explain mechanism behavior; they cannot add/remove key numbers, retune gammas, change df/scale, or define ATS subsets. Any prospective observation suggesting ±6, ±10, ±14, asymmetry, or another family is a future-version hypothesis only.
